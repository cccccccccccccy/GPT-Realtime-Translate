# 本地模型准备与离线导入

更新：2026-09-16。对应当前原生开发应用，默认模型为 `large-v3-v20240930_626MB`。

## 两个入口

- **下载并准备模型**：允许访问 Hugging Face，下载权重及必要分词资源，然后校验、编译、加载并预热。已有资源会优先复用。
- **离线加载已有模型**：只读取本地文件。缺失、损坏或不匹配时明确失败，不调用依赖原有的自动下载兜底。

两者均在成功完成短静音预热之后显示“本地模型已就绪”。取消后不发布新的就绪状态。Core ML 的某个编译步骤可能无法即时中断，界面会显示“正在取消”，当前步骤结束后释放模型资源。

## 导入目录要求

模型目录应包含对应 WhisperKit Core ML 模型组件，以及提供 `model_type`、`vocab_size`、`d_model` 的 `config.json`。当前支持标准 Whisper 词表及维度组合，加载后会再次核对实际模型维度。

完整、可移动的目录示例：

```text
MyWhisperModel/
  config.json
  MelSpectrogram.mlmodelc/
  AudioEncoder.mlmodelc/
  TextDecoder.mlmodelc/
  Tokenizer/
    config.json
    tokenizer.json
    tokenizer_config.json
```

也支持依赖能加载的对应 `.mlpackage` 组件，仍需相同的模型配置和分词资源。资源应为实际文件，当前不接受模型树中的符号链接。

程序依次查找模型内的 `Tokenizer`、模型目录直接附带的分词文件、应用缓存中的配套分词目录；导入本项目诊断下载的完整 Hub 缓存时，也能查找同一 `models` 树下的配套分词资源。已发现但不完整的分词目录会报错，不静默改用另一份缓存。

分词配置必须匹配模型词表，含必要语言、任务和时间戳标记。将其他模型的分词文件随意复制过来不能通过版本检查。导入后不向原模型目录写入新的完整性文件，适合只读导入目录；校验基线保存在应用模型缓存的 `ResourceIntegrity` 子目录。

## 版本与完整性

默认模型下载仓库 `argmaxinc/whisperkit-coreml` 固定提交：

`0f63a7800b00dd0226abd051b906c246e1907482`

默认分词仓库 `openai/whisper-large-v3` 固定提交：

`06f233fe06e710322aca913c1bc4249a0d71fce1`

这两个提交来自已经实际下载、运行的资源缓存记录。下载完成后核对文件的提交元数据，防止把其他版本的缓存误当作所请求版本。其他明确选择的模型族，其首次分词下载先解析到具体提交，再按该提交下载；仍需各自的质量与兼容性测试。

模型和分词文件纳入 SHA-256 本地基线；再次准备发现变化时拒绝启用。旧版写在模型目录内的权重基线继续读取。该机制用于发现本机文件变化，不是发布者签名，也不能认证任意第三方导入资源的真实性。

默认权重约 606 MiB，分词、Core ML 编译缓存及临时文件另占空间。模型文件体积不等于运行内存。实测冷准备约 55 秒、已有缓存加载约 2.3 秒；时间会随缓存、系统负载及模型变化。请在会议前完成准备。

## 本轮证据与局限

- 34 项回归通过，新增缺失/损坏/不完整分词资源、完整性变化、取消和下载版本不匹配等检查。
- 禁止诊断进程联网，完成时间点问题、坏死质疑、数字否定及中英双轨四组实际识别。英文 WER、中文 CER 与此前基线一致；英语 `irreversible` 的含义反转仍存在。
- 报告见 [离线资源实测目录](Validation/2026-09-16/asr-offline-assets/)。每份报告记录实际模型、分词目录、完整性记录和词表/编码维度。
- 固定提交的下载入口已联网运行并复用默认缓存；成功准备，约 63.75 秒，包含仓库查询和本轮冷准备。没有重新下载另一套权重，也没有发送音频或研究材料。
- 提前取消与准备中取消的回归不等于所有网络阶段、所有 Core ML 状态都能立即中断；不承诺即时停止不可中断的系统编译步骤。
- 原生界面已实测：导入已缓存的默认模型 → 离线加载 → 输入及准备按钮禁用 → 取消提示 → 取消完成后恢复按钮 → 再次离线加载成功，主窗口显示“本地模型已就绪”。未开启 Zoom 或麦克风采集，也未启用云端文字。该 UI 测试未在进程层禁网；禁网证据来自前述诊断测试。
- `small` 多语言模型也已实际下载、严格离线加载并完成相同四组识别，见[模型对比记录](ASR_BENCHMARK_2026-09-16.md)。默认模型未改动。
- `openai_whisper-large-v3_947MB` 已在独立缓存下载、校验和预热；随后禁网完成七组识别。该较大模型仍有相同关键术语错误，本轮双轨延迟更高，因此没有替换默认模型，见[关键字词与模型比较](ASR_CRITICAL_WORDS_2026-09-16.md)。
- 此轮改动解决资源准备边界，不代表医学语音质量或 90 分钟会议验收通过。
